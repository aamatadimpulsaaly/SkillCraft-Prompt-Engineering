# Task 2: Prompting for Creativity

**Internship:** SkillCraft Technology  
**Domain:** Prompt Engineering  
**Status:** Completed

## Objective
To explore how different prompting techniques influence creative AI-generated responses.

## Work Completed
- Designed a simple prompt to generate startup ideas.
- Improved the prompt with detailed instructions and context.
- Created a Few-Shot prompt using examples.
- Compared the generated outputs based on tone, creativity, detail, structure, and practicality.

## Key Learnings
- Detailed prompts help generate more structured and relevant ideas.
- Tone instructions influence the style of responses.
- Few-Shot prompting guides AI using examples.
- Prompt structure can improve the usefulness of creative outputs.
